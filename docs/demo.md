# HeatSafe AI — Demo Script

Target length: **3 minutes**. Do not improvise. Rehearse twice before recording.

## Before you start

- Run one analysis for Phoenix, AZ so the server cache is warm — this removes polling latency from the recording.
- Close dev tools. Use a clean browser profile at 1440×900.
- Confirm the status badge reads `● LIVE FortyGuard`. If the API is down, `● DEMO DATA` is acceptable and honest — say so out loud.
- Have `/how-it-works` open in a second tab as backup.

## Script

| # | Action | Say |
| --- | --- | --- |
| 1 | Open landing page | "HeatSafe AI — hyperlocal heat intelligence." |
| 2 | Read the hero | "Know where heat becomes a problem." |
| 3 | Click **Analyze Heat** | — |
| 4 | Select Phoenix, AZ | "One U.S. location, analyzed at 100-meter resolution." |
| 5 | Map renders | "This is FortyGuard temperature intelligence, not a city-wide average." |
| 6 | Click the hottest cell | "A nine-degree difference two blocks apart." |
| 7 | Show the HeatSafe Risk card | "This score is our model — HeatSafe Risk v1.0 — built on FortyGuard data." |

| 9 | Scrub the 12-hour forecast | "When heat peaks, and how long it persists." |
| 10 | Show a heat event | "This uses FortyGuard's native exceedance and persistence analytics." |
| 11 | Ask the AI Advisor | "The AI explains the facts. It cannot invent or change a number." |
| 12 | Open **Heat-Aware Routes** | — |
| 13 | Compare two routes | "Real road routes, sampled against real heat cells." |
| 14 | Open **City Heat Planner** | "Switch to planner mode — city-scale decisions." |
| 15 | Show priority zone #1 + evidence | "Prioritized by risk, persistence, and heat-exposed area." |
| 16 | Show budget scenario | "A scenario estimate — clearly labeled, not an engineering cost." |
| 17 | Land on the footer | "See the heat. Understand the risk. Act with confidence." |

## Backup plan

If the live API fails mid-recording: do not restart. Point at the `● DEMO DATA` badge and say *"the product degrades honestly — it always tells you where the number came from."* That is a stronger moment than a perfect run.

## Do not show

Debug panels, `activity_id`, raw JSON, the editor, terminal, or any localhost URL.
